# Сервер After Ai на Анфе

Раздаёт только страницу скачивания, лицензию, установщики и подписанный манифест After Ai. Никаких API-ключей пользователей, проектов AE и истории генераций на сервере нет.

Порт по умолчанию: **47683/TCP**. На Linux достаточно Python 3: `python3 server/server.py`. Установка зависимостей не требуется. Альтернативный сервер для Node.js: `node server/server.js`.

После сборки скопируйте на сервер `server/server.js` и `dist/site/` с сохранением относительного расположения. Запуск из корня проекта: `node server/server.js`. Адрес проверки: `http://SERVER-IP:47683/health`.

Публичные параметры запуска:

- `AIFLOW_PORT`: порт, по умолчанию 47683.
- `AIFLOW_HOST`: адрес привязки, по умолчанию 0.0.0.0.
- `AIFLOW_PUBLIC_ROOT`: абсолютный путь к готовому `dist/site/`, если он расположен отдельно.

Для внешних пользователей в установщике должен быть указан доступный снаружи адрес манифеста. Локальный адрес сервера для интернета не подходит. Пробросьте выбранный порт на роутере и сообщите владельцу сборки внешний адрес или домен. HTTPS можно добавить через имеющийся обратный прокси, не занимая дополнительные стандартные порты.

После настройки роутера выполните `node scripts/set-update-address.js https://YOUR-PUBLIC-HOST:PORT` и опубликуйте изменённый `updates/location.json` на GitHub. Установленные панели узнают новый адрес через этот публичный указатель; переустановка не нужна. Подпись каждого обновления всё равно проверяется независимо от адреса.

Обновление сайта: сначала загрузить новый установщик в `dist/site/downloads/`, затем атомарно заменить `dist/site/updates/experimental.json`. Старые установщики сохранять. Не менять байты уже опубликованной версии; для исправлений увеличивать версию. Запросы на произвольные файлы, каталоги и другие методы сервер отклоняет.
