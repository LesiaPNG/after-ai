# Разработка After Ai

After Ai — самостоятельный CEP-плагин для After Effects. У него собственные версии, установщик, ключ подписи и канал обновлений. Интеграции других приложений не меняют его механизм обновления.

Автор оригинального проекта: Ачкасова Олеся. Изменённые версии обозначайте как изменённые; сохраняйте COPYRIGHT, LICENSE и уведомления сторонних компонентов.

Для проверки ядра: `npm test`. Для браузерного теста: `npm install`, `npx playwright install chromium`, затем `npm run test:ui`. Используйте синтетические данные. Не добавляйте реальные ключи, проекты пользователей, журналы, профили браузеров или результаты генераций.

Для нового выпуска измените `version` в package.json и выполните `npm run build:release -- --manifest-url https://YOUR-HOST/updates/experimental.json`. Сборка создаёт установщик Windows, подписанный манифест и готовую папку сайта. Исходники и установщик одной версии публикуйте вместе.

Сборке нужен Windows и компилятор .NET Framework, входящий в Windows. Секретный ключ подписи находится отдельно от репозитория: по умолчанию `%LOCALAPPDATA%\AIFlowRelease\signing-private.pem`. Сборщик создаёт его только при отсутствии и никогда не выводит содержимое. В репозитории хранится только публичный ключ. Тот же секретный ключ нужен для всех дальнейших обновлений: хранитель проекта должен сохранить его отдельно. Не присылайте его в чат, не коммитьте и не включайте в архивы проекта.

Для CI путь к ключу задаётся переменной `AIFLOW_SIGNING_KEY_FILE`; сам ключ вводится владельцем через защищённое хранилище CI. Для переноса сайта без переустановки плагина сборка поддерживает `--discovery-url`: это публичный JSON с полем `manifestUrl`. Указатель не содержит секретов; любая полученная через него версия всё равно должна пройти проверку криптографической подписи.
