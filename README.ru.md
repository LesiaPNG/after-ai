# After Ai 0.0.1 — экспериментальный плагин для After Effects

Самостоятельная свободная CEP-панель для Windows и AE 2024 / 2026: промт, модели OpenRouter, изображение на входе, видео на выходе, импорт и история расходов. Автор: **LesiaPNG (Ачкасова Олеся)**. Лицензия: **GNU GPLv3**, см. LICENSE и COPYRIGHT. Версия 0.0.1 предназначена для небольшого круга тестировщиков и ещё не является альфа-версией.

After Ai имеет собственный установщик и канал обновлений. Его можно использовать из других проектов по открытой лицензии; установка или обновление Resizer не является установкой или обновлением After Ai.

## Установка и запуск

1. Скачайте и откройте `After-Ai-0.0.1-Setup.exe`. Сохраните проект и закройте After Effects. Установка выполняется для текущего пользователя, без прав администратора.
2. В установщике отметьте разрешение загрузки неподписанных панелей и нажмите «Установить After Ai». Установщик копирует только файлы плагина в `%APPDATA%\Adobe\CEP\extensions\studio.aiflow.ae` и включает `PlayerDebugMode=1` для CEP 11 и 12. Это разрешает загрузку неподписанных CEP-панелей, включая другие установленные неподписанные расширения.
3. Перезапустите AE. Откройте **Окно → Расширения → After Ai** / **Window → Extensions → After Ai** и закрепите панель.
4. Для экспорта кадров включите в настройках AE **Скрипты и выражения → Разрешить скриптам записывать файлы и осуществлять доступ к сети** / **Allow Scripts to Write Files and Access Network**. Эта настройка относится ко всем скриптам AE. Сам установщик её не меняет.
5. Нажмите шестерёнку в панели, введите свой ключ OpenRouter и нажмите **Сохранить ключ**. Ключ вводите только локально, не отправляйте в чат.

Панель использует встроенный Node CEP и Windows PowerShell 5.1. Отдельная установка Node.js, Python или сервера для её работы не нужна.

## Обновления After Ai

Панель автоматически проверяет собственный экспериментальный канал на сайте проекта. Новая версия скачивается в фоне только после проверки подписи манифеста; установщик проверяется по SHA-256. Кнопка «Установить обновление» запускает установщик и предлагает закрыть AE. Текущая версия продолжает работать, если сайт временно недоступен. В шестерёнке есть ручная проверка обновлений.

Проверка обновлений не передаёт серверу API-ключ, промты, файлы проекта или историю генераций. Секретный ключ подписи хранится у автора отдельно от репозитория; в плагине находится только публичный ключ. Контракт сборки описан в CONTRIBUTING.md, размещение сайта — в server/README.md.

## Генерация

Сохраните проект `.aep` / `.aepx`, откройте композицию, выделите один слой. Нажмите **Взять слой из AE**, прикрепите файл или перетащите его из Проводника. MVP принимает PNG/JPG/WEBP до 12 МБ.

Введите промт, выберите модель, длительность, разрешение и пропорции. Список параметров загружается из каталога OpenRouter. Вложение используется как начальный кадр; модель должна заявлять поддержку `first_frame`. Нажатие **Сгенерировать** отправляет платный запрос в ваш аккаунт OpenRouter.

Для статичного PNG/JPG/WEBP берётся исходный файл выбранного слоя. Для видео, прекомпозиции или другого доступного источника экспортируется кадр исходника на позиции курсора; учитываются Stretch и Time Remap. Эффекты, маски и трансформации самого выбранного слоя в этот кадр не запекаются и остаются на слое после замены.

Кнопка **Кадр композиции** экспортирует всё видимое содержимое текущей композиции с обработкой. Результат этого режима добавляется новым слоем, чтобы обработка композиции не применялась повторно. Этот режим подходит для текста и shape-слоёв. Отправка целого видеофрагмента в MVP пока не предусмотрена.

## Возврат результата

Панель запоминает исходный проект, композицию и слой. Смена выделения во время генерации не меняет место вставки.

- Совпадают ширина, высота и Pixel Aspect → источник выбранного слоя заменяется через `AVLayer.replaceSource`, настройки слоя сохраняются.
- Размер отличается → предупреждение и новый слой в той же композиции со **Scale 100%**, без подгонки. Размер предварительно оценивается перед отправкой и проверяется после импорта.
- Исходный слой удалён, заблокирован или его источник изменён → новый слой.
- Открыт другой проект или удалена композиция → видео остаётся на диске. Откройте нужный проект и нажмите **Вставить в AE** в истории.

Замена — одна операция Undo. Исходные файлы не перезаписываются. Проект после вставки сохраняйте обычным способом. Длительность слоя, Stretch и Time Remap не подгоняются под новую длительность: проверьте начало и конец видео на таймлайне.

## Файлы и расходы

Рядом с `MyProject.aep` создаётся `MyProject.aiflow`: `inputs` — экспортированные кадры, `outputs` — видео, `ledger.json` — задания и расходы. В окне Project файлы группируются в **AI Generations**. Переносите папку `.aiflow` вместе с проектом.

Оценка рассчитывается по распознанному тарифу за секунду. Если единица тарифа неизвестна, показывается «—»; в дополнительных настройках можно указать свою ставку $/сек. Фактическая сумма берётся из `usage.cost` OpenRouter. Отсутствующая стоимость остаётся «уточняется», а не заменяется нулём. Комиссии пополнения, налоги и запросы из других приложений в счётчик не входят.

Стоимость записывается до скачивания и вставки. Один ID задания учитывается один раз, включая неудачные задания, если провайдер сообщил списание. После перезапуска нажмите **Проверить** в истории. Повторная платная отправка автоматически не выполняется. Если соединение оборвалось до получения ID, сначала проверьте Activity в OpenRouter.

Для одного проекта используйте одну панель: одновременное редактирование общего журнала из двух экземпляров AE в MVP не поддерживается.

## API-ключ

Хранится отдельно от проектов в `%LOCALAPPDATA%\AIFlowAE\openrouter.dpapi`, зашифрован Windows DPAPI для текущего пользователя. Удаляется кнопкой **Удалить** в настройках. Не переносите и не публикуйте этот файл.

Ключ не передаётся в аргументах запуска, не записывается в журнал и не возвращается в диагностике. Обработчик обращается только к фиксированному API OpenRouter; возвращённые ссылки не используются для передачи ключа. Ошибки и HTTP-ответы целиком в интерфейс не выводятся. Промт и выбранное изображение передаются OpenRouter и выбранному провайдеру только при запуске генерации; сторонний файловый хостинг не используется.

## Удаление и ограничения

Закройте AE и удалите только `%APPDATA%\Adobe\CEP\extensions\studio.aiflow.ae`. Проекты и результаты сохраняются. Ключ удалите через панель заранее, если он больше не нужен. Установщик не выключает режим разработки автоматически, поскольку его могут использовать другие панели. Предыдущая версия After Ai при переустановке сохраняется в `%LOCALAPPDATA%\AIFlowAE\extension-backups`.

Если панель не появилась, полностью перезапустите AE и проверьте, что распакован весь комплект. Корпоративные ограничения могут запрещать PowerShell или неподписанные панели. Доступность видео API зависит от OpenRouter и аккаунта; ошибка 404 отображается в панели без переключения на другой сервис.
