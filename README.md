# ✦ After Ai

Нейрогенерация внутри Adobe After Effects. Самостоятельный свободный плагин для Windows: изображение или слой AE → промт и модель OpenRouter → видео в исходной композиции.

## Установка

1. Скачайте `After-Ai-0.0.1-Setup.exe` из выпуска v0.0.1.
2. Сохраните проект и закройте After Effects.
3. Откройте установщик, отметьте разрешение загрузки неподписанных экспериментальных панелей, нажмите «Установить After Ai».
4. Откройте AE → **Window → Extensions → After Ai**.
5. Разрешите скриптам AE запись файлов и доступ к сети. В шестерёнке панели введите свой ключ OpenRouter локально.

Экспериментальный установщик пока не подписан сертификатом издателя Windows. Подпись манифестов обновлений — отдельная проверка целостности и подлинности файлов After Ai.

Плагин бесплатный. Генерации оплачиваются отдельно через аккаунт OpenRouter. Поддерживаются AE 2024 / 2026; реально проверена AE 2026. Вход — PNG/JPG/WEBP до 12 МБ. Входное видео целиком пока не загружается: можно взять кадр слоя или композиции.

Панель оценивает цену, учитывает расход по проекту и хранит результаты рядом с AEP. Совпали размеры — замена исходника выбранного слоя; другой размер — новый слой при Scale 100%, с предупреждением. API-ключ хранится средствами Windows DPAPI отдельно от проектов.

## Независимые обновления

After Ai имеет собственные версии, установщик, подпись и серверный канал. Обновление другого приложения, включая Resizer, не обновляет After Ai. Панель проверяет новую версию и её подпись, скачивает проверенный установщик и предлагает установку. Для установки нужно закрыть AE; сбой сервера не мешает работе установленной версии.

Сайт размещён на сервере автора, порт 47683/TCP. Пока внешний адрес не настроен владельцем роутера, сайт доступен в локальной сети. Сам установщик доступен через GitHub Releases. Внешний адрес подключается позже без переустановки панелей через публичный `updates/location.json`. Внутренние адреса сети в репозиторий и установщик не включаются. До подключения публичного сервера панель сверяет версию с подписанным манифестом текущего выпуска в GitHub.

## Разработка и размещение

[Подробное руководство](README.ru.md) · [Сборка и вклад в проект](CONTRIBUTING.md) · [Сервер сайта и обновлений](server/README.md) · [Проверки](VERIFICATION.md).

`npm test` — проверки ядра и подписанных обновлений. `npm run test:ui` — изолированный тест интерфейса с синтетическим API. `npm run build:release` — сборка установщика Windows и сайта; публичный адрес обновлений задаётся аргументом `--manifest-url`.

Демонстрационные рабочие PSD, проекты AE, история генераций, браузерные профили и реальные API-ключи не входят в репозиторий или установщик. After Ai не связан официально с Adobe или OpenRouter.
